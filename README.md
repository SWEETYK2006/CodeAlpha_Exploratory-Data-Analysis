# Exploratory Data Analysis (EDA)

## About the Project

This project was completed as part of my **CodeAlpha Data Analytics Internship**.

The objective of this project is to explore a transactional dataset, identify patterns and trends, analyze data quality, and generate meaningful insights using statistics and visualizations.

## Dataset

The dataset contains **10,000 transactions** with information including:

* Transaction ID
* Transaction Date
* Payment Method
* Location
* Quantity
* Price Per Unit
* Total Spent
* Item

## Questions Explored

The analysis focuses on questions such as:

* What are the most frequently purchased items?
* Which items generate the highest sales?
* Which payment methods are most commonly used?
* How are transactions distributed across locations?
* How do sales change over time?
* Are there missing values or other data-quality issues?

## Data Exploration

The dataset was examined to understand:

* Number of rows and columns
* Variables and data types
* Basic statistical information
* Missing values
* Minimum and maximum values
* Transaction and sales patterns

## Key Analysis

The project includes analysis of:

* Item performance
* Payment methods
* Location
* Sales by item
* Monthly sales trends
* Quantity sold
* Missing values and data-quality issues

## Visualizations

The following visualizations were created:

1. EDA Summary
2. Item Analysis
3. Payment Method Analysis
4. Location Analysis
5. Sales by Item
6. Monthly Sales Trend

## Data Quality

Missing values were identified in several columns, including:

* Payment Method
* Location
* Item
* Transaction Date

These issues were considered during the exploratory analysis.
